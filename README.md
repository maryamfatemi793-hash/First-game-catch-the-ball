# Maryam Apple Catcher

A simple apple-catching game built with Pygame.

## How to Play

- Use the left and right arrow keys to move the basket.
- Each apple caught adds 1 to your score.
- Each apple missed adds 1 to missed.

## Levels

Choose a level before the game starts:

- Level 1: Easy (speed 4)
- Level 2: Medium (speed 7)
- Level 3: Hard (speed 11)

## Requirements

pip install pygame

## Run

python game.py
